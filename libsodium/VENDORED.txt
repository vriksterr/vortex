builds without a separately installed libsodium.

              (verified with: minisign -Vm libsodium-1.0.22-stable.tar.gz -P <key>)
  Licence   : ISC, see LICENSE in this directory.

Nothing in this directory has been changed. Vortex's top-level `make` (or
`./sodium.sh`) configures it out of tree into ../.sodium/ and links the
resulting static library into the vortex executable; the source tree here is
never written to by a normal build.

To update: download a newer release, verify its minisign signature with the
key above, replace the contents of this directory (keep this file), update the
version and hash above, rebuild and run the tests.
